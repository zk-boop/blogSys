# 上传图片不纳入可见性规则

`/uploads/**` 是公开静态资源，被封禁作者与草稿的封面图仍可通过 URL 直接访问。我们**刻意**不在本次变更中处理它，接受这一残留风险。

原因是它要求把静态资源改成带鉴权的动态读取，缓存与 CDN 都要重新考虑，成本与可见性模块本身不是一个量级；而被封禁或转为草稿的内容，其封面通常已随文章本身公开过一轮，事后封堵的收益有限。

## Consequences

已知残留：图片 URL 一旦公开即长期可取，且不可撤回。请不要把它当作本次重构的遗漏来"顺手修掉" —— 如果将来要处理，应当作为独立候选重新评估（按可见性分目录，或让不可见内容的文件名不可猜）。
