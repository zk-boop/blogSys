# v2 Backlog(由 v1 砍掉的需求)

以下功能在 v1 明确砍掉,留在后续迭代。架构上均已预留扩展位,不需要重构即可接入。

| 功能 | 状态 | 预留情况 |
|---|---|---|
| 嵌套评论 | 待做 | `comments.parent_id` 字段已建,v2 直接支持 |
| 图片上传 | 待做 | 文章内容为 Markdown,图片 URL 直接可存;后续接 OSS/本地存储 |
| 全文搜索 | 待做 | v1 用 LIKE 兜底;v2 可换 Elasticsearch |
| 草稿箱 | 待做 | 文章 `status` 字段预留(1=已发布) |
| 私信 | 待做 | 独立表,不影响现有结构 |
| RSS 订阅 | 待做 | 读取文章列表即可实现 |
| 文章审核流 | 待做 | 依赖 `status` 字段扩展 |
| 用户头像上传 | 待做 | 当前 DiceBear 默认头像 |
| 个人主页/他人主页 | 待做 | 按 user_id 过滤文章列表即可 |

## 开发原则

1. v1 以跑通闭环为唯一目标,不提前实现 v2 功能
2. 任何 v2 需求不得要求修改 v1 的表结构(已建字段除外)
