# v2 状态与 v3 Backlog

## v2 已完成

| 功能 | 说明 |
|---|---|
| 嵌套评论 | 回复挂在对应一级评论下,支持展开/收起 |
| 个人主页/他人主页 | `/user/:id`,含公开文章列表 |
| 标题/内容搜索 | `keyword` LIKE 匹配,标题+内容 |
| 草稿箱 | `status=0`,仅作者/管理员可见,个人中心可管理 |
| 图片上传 | 5MB 限制,本地存储,正文/封面均可上传 |
| 博客封面 | `articles.cover` 字段,卡片与详情展示 |

## v3 已完成

| 功能 | 说明 |
